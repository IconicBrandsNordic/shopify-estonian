# Glossary and conventions

The choices behind the translations, so additions stay consistent.

## Conventions

| Topic | Use | Not |
|---|---|---|
| Tone | Informal *sina* ("Kas vajad abi?") | Formal *teie* |
| Cart | `Ostukorv` | `Käru` (colloquial) |
| Add to cart | `Lisa ostukorvi` | |
| Password | `parool`, every time | `salasõna` (don't mix the two) |
| VAT | `käibemaks`, short `KM` | |
| County (address) | `Maakond` | `Provints` (Estonia has *maakonnad*) |
| Home (breadcrumb) | `Avaleht` | `Kodu` |
| Breadcrumb | `Jäljerada` | `Leivapuru` (literal "bread crumb") |
| Clear (filters) | `Tühjenda` | `Selge` ("clear" as in obvious) |
| Duties | `Tollimaksud` | `Kohustused` ("obligations") |
| Sale badge | `Soodus` / `Allahindlus` | `Müük` ("sale" as in selling) |
| Backorder | `Järeltellimus` | `Järelbestellus` (Germanism) |
| Rejected (status) | `Tagasi lükatud` | `Hülgav` |
| We accept (payment icons) | `Aktsepteerime` | `Me nõustume` ("we agree") |
| Read more | `Loe rohkem` | |
| Discount code | `Sooduskood` | |

## Lowest price in 30 days (EU price rule)

Estonia applies the EU rule that a price reduction is measured against the lowest price of the previous 30 days. No set wording is required for a label. If you show one, `madalaim hind 30 päeva jooksul enne hinnalangust` is clear and in use on large Estonian fashion sites. This is not legal advice.

## Common machine-translation traps

- English words with two meanings get the wrong one: *Clear* (tühjenda / selge), *Sale* (soodus / müük), *Home* (avaleht / kodu).
- Plurals: Horizon only has `one` and `other`, which is all Estonian needs.
- Placeholders like `{{ count }}` must stay exactly as they are; word order around them often changes in Estonian.
